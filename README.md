# WORLD AI — Phase 1

Frontend/PWA foundation for the WORLD AI platform.

## Run

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Next phases

- Phase 2: Firebase Auth, Firestore, Storage
- Phase 3: Secure server-side AI API routes
- Gemini and Grok keys will be stored only in server-side environment variables, never in the browser.
