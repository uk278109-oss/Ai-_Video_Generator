# DOG AI — AppGeyser

1. Deploy this repository to Vercel.
2. Copy the final HTTPS Vercel URL.
3. In AppGeyser choose the website/web-app conversion option.
4. Paste the Vercel URL.
5. Set app name to `DOG AI`.
6. Use `public/pwa-512.png` as the app icon if AppGeyser asks for one.
7. Build/download the APK from AppGeyser.

For a more controlled Android app, use the included `android/` Android Studio project instead.
